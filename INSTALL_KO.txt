# 미지록 · elsewhere 4.0

## 이미 사용 중인 GitHub 사이트에 올리기

1. 기존 사이트에서 메뉴 → 전체 백업으로 기록을 받아 두세요.
2. `ELSEWHERE_V4_UPLOAD.zip`을 압축 해제하세요.
3. 압축 해제한 폴더 안의 파일 전체를 선택하여, 기존 index.html이 있는 GitHub 저장소 위치에 올리세요. 하위 폴더는 없습니다. ZIP 파일 자체를 올리는 것이 아닙니다.
4. 변경을 커밋하고 GitHub Pages 배포가 끝나면 사이트를 새로고침하세요.
5. 기존 여행 사이트 계정으로 로그인하세요.

기존 Supabase 주소와 공개 키가 config.js에 들어 있습니다. 기존 프로젝트의 travel_records와 travel-files를 그대로 사용합니다. 기존 사이트가 작동하고 있었다면 SQL을 다시 실행할 필요가 없습니다. 계정 비밀번호와 secret 키는 포함하지 않습니다. 기존 데이터에 삭제/변경 SQL을 실행하지 않습니다.

## 이번 구현

- 홈: 흰색 전시장. 기록 표지·필기 미리보기, 크기가 다른 편집형 배치, 작은 캡션. 추가·도감·백업·휴지통은 메뉴 안에 있습니다. 추천/광고형 예시 없음.
- 상세: 기록 제목, 계기, 종이, 장소, 동선, 시간표, 체크리스트, 스냅샷을 읽는 전시 화면. 메뉴 또는 하단에서 작업대로 이동.
- 작업대: 같은 기록의 후보 장소/동선/실제 지도/시간표/체크리스트/종이 전환.
- 필기: 고해상도 캔버스, 저장된 화면과 입력 중 획 분리, 중간점 보간, 완만한 압력 반응, coalesced 입력, 손가락 이동·확대, 획/부분 지우개, 올가미 다중 선택·이동·복제·확대·축소·삭제, 실행 취소/재실행.
- 종이: 이미지·PDF 배경, 전국 백지도, 텍스트, 일정·체크 항목 가져오기, PNG/PDF 내보내기, 완성본 표지 설정.
- 시간: 미입력 이동·대기는 미확인으로 유지. 미확인 구간 뒤 시간도 미확인. 예약 시각은 기준점으로 보이며 도착 가능성 확인 표시. 순서/포함 변경 시 관련 이동값 재확인. 운영시간·휴무·축제 기간 검토.
- 링크: 여러 URL 대기열, URL에 담긴 이름·좌표 추출, 중복 URL 방지, 이름 확인 후 담기, 원문 링크 보관.
- 보관: 후보/방문 장소 보관함, B안 복제, 백업/복원, 휴지통, 저장 실패 시 이 기기 IndexedDB 복구 사본. 충돌 시 자동 덮어쓰기 중지.

## 범위와 검증 상태

모든 사이트의 장소명·주소·운영시간·예약일을 자동 수집하는 서버 기능은 이 배포본에 연결되어 있지 않습니다. 링크 자체에 없는 정보는 원문을 확인하여 입력합니다. 대중교통 실시간 경로/시간표도 외부 지도 앱에서 확인합니다. 실제 지도에 그어진 선은 방문 순서이며 길찾기 결과가 아닙니다.

장소 정보·여행 후보·방문 경험을 구분했습니다. 독립 장소 보관함 레코드에 장소 기본 정보와 방문 이력을 저장하며, 여행에서 장소를 제외하거나 여행을 휴지통으로 옮겨도 보관함에 남습니다. 기존 DB의 JSON 기록 안에 보관함을 추가하므로 새 테이블이나 삭제 SQL 없이 이전 기록과 호환됩니다. 최초 실행 시 기존 장소를 보관함으로 모읍니다.

프로덕션 빌드와 TypeScript 검사 통과. 단위 테스트로 미확인 시간 전파·0분·예약 기준점·행사 기간·선분 지우개·부분 지우개·올가미 내부 판정을 검증했습니다. 실행 환경의 브라우저 실행 권한 문제로 브라우저 자동 테스트, 시각 검증, 실제 iPad/Apple Pencil 사용감 및 실제 계정의 서버 저장은 검증하지 못했습니다.

## 원본 개발

source에서 pnpm install --frozen-lockfile, pnpm build. web에 파일이 만들어집니다. pnpm dev로 개발합니다. node node_modules/typescript/bin/tsc --noEmit으로 타입 검사합니다. Node 22.13 이상.

기존 SQL은 최초 설정용 참고 파일입니다. 기존 운영 DB에 다시 실행하지 마세요.
